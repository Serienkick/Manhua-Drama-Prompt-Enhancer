# 漫剧提示词维度规则库（活文档）

> **如何加维度**：直接新增/修改下面的 `## 维度：xxx` 小节，enhance.py 会把全部小节
> 原样拼进系统提示——**改规则文件即可扩展，脚本无需改动**。删除小节即停用该维度。
> 每条规则是给 LLM 的硬约束，写得越具体执行越稳。

## 维度：cast 视觉锚（身份锁）

- 先提炼主角视觉卡：发型/发色/瞳色/服装颜色/标志物，外加场景主基调（主色调/光线/天气/氛围），合计 ≤120 字。
- 只写「恒定不变」的视觉属性，禁止把动作、事件、情绪写进 cast。
- 全部分镜的画面必须与 cast 视觉严格一致，禁止悄悄换发型/换装/换配色。

## 维度：单主角画面纪律

- 每个分镜画面默认只出现主角一人。
- 剧本中其他角色（邻居/摊主/路人/对手）只作为剧情被提及，一律不画进画面。
- 禁止人群、围观、多人同框、背景行人的描述。

## 维度：动作幅度与景别（防畸变）

- 优先中近景、上半身景别——人脸在画面中占比越大，结构越稳定。
- 动作用小中幅：转头、抬头、低头看、缓步、伸手；避免奔跑、跳跃、挥舞、旋转等大幅动作。
- 每个分镜只安排一个主要动作，动作之间留呼吸空间，不要连续堆叠。

## 维度：时序连续性

- 相邻分镜的动作必须连续递进：上一镜头结束的姿态 = 下一镜头的起始姿态。
- 非切换镜头以「承接上一段：」开头描述延续；只有真正的镜头切换点才允许画面跳变并显式标注。
- 场景内光线/色调保持延续，切换后风格仍要一致。

## 维度：动感与画面健康

- 禁止静止画面、大面积纯色、长时间空镜头——图生视频模型对静止内容会快速劣化。
- 每个分镜必须写明一个明确的画面运动元素（人物小动作或镜头缓推/缓摇）。
- 描述具体、可视、可画：不写抽象情绪（"他很开心"→写"嘴角上扬，眼睛弯起"）。

## 维度：运动三分法（单主角画面的运动配比）

单主角 + 小动作纪律下，画面动感按此配比设计，每个分镜三种运动最多出现两种：

- **镜头运动 = 主力**（安全）：缓推/缓拉/横移/微摇，一次只选一种，1 秒内幅度要小——
  "缓慢向前推"安全，"快速变焦"全画面重采样会糊。机理：运镜是像素整体变换，
  不需要模型重新想象人体结构。
- **主角小动作 = 辅助**：转头/呼吸/眼神变化/抬手，提供"活"感；大动作（奔跑/挥舞）
  是畸变高发区，仅剧情必需时才用。
- **环境运动 = 点睛**（安全且加氛围）：风吹衣角、蒸汽、飘落物、光斑闪烁、雨滴——
  不涉及人物结构，零崩坏风险。
- 相邻分镜的运镜方向要衔接（上镜缓推 → 下镜继续缓推或静止，避免突然反向横移）。

## 维度：光线稳定性

- 每个分镜写明光源方向，且全片保持一致（光从左侧来就始终从左侧来）——光线跳变是画面漂移的主因之一。
- cast 里的场景基调（主色调/光线）延续到每个分镜，不得中途改变时间（清晨→正午）或天气。
- 避免逆光、强明暗对比镜头——小模型逆光下人脸结构容易崩坏。

## 维度：构图安全

- 主体放画面中央或三分位，头顶留白（headroom），避免主体贴画面边缘——贴边主体易被裁切或拉伸变形。
- 构图越简单越稳：一个主体 + 一个背景层次，避免复杂前景遮挡。

## 维度：信息密度控制

- 一个分镜只承载一个信息点：一个动作 + 一个情绪，不叠加。
- 旁白文本长度与 1 秒画面匹配：约 3-4 个汉字/秒，超出会被截断——每个分镜的 text 控制在 60 字内且优先短句。
- 避免跨镜悬空动作（"手举到一半"），动作要在本镜内完成。

## 维度：触发词回避

- 画面内不出现文字类描述（招牌上的字、报纸标题、手机屏幕）——模型画文字必出乱码。
- 避免手部特写、张大嘴喊叫等口型大张描述——手和嘴是崩坏重灾区；说话写「嘴唇微动」。
- 避免镜面/水面倒影中出现人物的描述（反射内容不受控）。

## 维度：道具连续性

- 主角手持物（馒头/钱/水果）必须写进分镜 text，且跨镜保持，直到剧情明确放下或交出。
- 手中物品的消失/出现是无对话的穿帮，比角色换装更显眼。

## 维度：输出适配

- 分镜条数 = 用户指定的 segments，每条 text ≤60 字（1 秒画面装不下长句）。
- action 字段写画面运动描述：人物动作或运镜（推/拉/摇/固定）。
- 语言与剧本一致（中文剧本输出中文分镜）。
